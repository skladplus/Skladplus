# Skladplus

Веб-платформа фулфилмента: приёмка, адресное хранение, сборка и отправка заказов,
возвраты и биллинг. Заменяет связку «Google-таблица + чат + Telegram-бот».

## Быстрый старт

```bash
corepack enable
pnpm install
pnpm dev
```

Node — версия из `.nvmrc`, пакетный менеджер — из поля `packageManager`.
Реальные переменные окружения живут вне репозитория (`~/.skladplus/env`);
в git только `.env.example`.
