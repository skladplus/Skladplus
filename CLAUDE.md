# CLAUDE.md

Правила проекта — в [AGENTS.md](AGENTS.md). Здесь они сознательно не дублируются:
копия разъезжается с оригиналом, а Codex читает только `AGENTS.md`, поэтому правило,
попавшее лишь сюда, для второго разработчика не существует. CI проверяет отсутствие
дублей.

Шаг 0 любой сессии — `bash scripts/context.sh`. У Claude Code он же висит на
`SessionStart` в `.claude/settings.json` и срабатывает без напоминания.
