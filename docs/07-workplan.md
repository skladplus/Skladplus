## Ритм и синхронизация

- Ветка живёт максимум день; утром `git fetch && git rebase origin/main`.
  Незаконченное — за feature-флагом (реестр модулей это поддерживает из коробки).
- Правки схемы Prisma и общих реестров — `[contract]`, маленькими PR, первыми.
- Каждая задача таблиц выше = один issue в GitHub с ссылкой на §04/§05/§06;
  issues создаются после мержа этого PR, назначение — по колонке «владелец».
- Definition of Done — из `AGENTS.md`; для UI-задач дополнительно инвентарь
  состояний (06 §3); для auth и всего, что трогает деньги/права, —
  `/security-review` до мержа.
- Пятница — сверка бэклога: что разблокировали ответы заказчика, что
  переносится. Решения — в 02-architecture, вопросы — в findings-backlog,
  личное «что сделал» — в PROGRESS.
